## 기본 브랜치를 master에서 main으로 변경

- 앞서 `master`를 기본 브랜치로 올렸으나, 사용자의 원래 의도는 "`main`으로 바꿔서 거기에 올리는 것"이었다. 요청을 문자 그대로 해석한 결과라 다시 정리했다.
- `git branch -m master main` → `git push -u origin main` → GitHub 기본 브랜치를 `main`으로 변경 → 원격 `master` 삭제. 커밋 이력은 그대로 유지했다.
- 함께 만든 전역 슬래시 명령어 `/gh-push`의 기본 브랜치도 `main`으로 맞췄다. 이제 `master` 브랜치를 발견하면 `main`으로 자동 변경한다.
  - 관련 파일: `~/.claude/commands/gh-push.md`, `~/.claude/scripts/gh-push.sh`, `~/Desktop/gh-push-명령어.txt`
